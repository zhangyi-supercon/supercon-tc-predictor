# 数据驱动的超导临界温度预测：21263 条数据踩过的两个坑

> 实际做 Tc 预测时踩的坑，写出来给同行参考。工具在 [tcpredict.top](https://tcpredict.top)，欢迎试用交流。

## 背景

UCI 的 Superconductivity 数据集（21263 条，81 个特征）是做超导临界温度（Tc）机器学习预测最常用的公开数据。它来自 NIMS SuperCon 数据库，每条记录包含材料的化学组成、元素统计特征和实测 Tc。

数据本身很好，但直接拿来训练容易掉进两个坑。

## 坑一：同一种材料的多条记录会造成"假高分"

这个数据集里，同一种材料在不同温度/压力条件下的测量会算成多条记录。比如某种铜氧化物，可能同时存在 Tc=92K、95K、90K 三条记录，化学式几乎一样，只是特征略有差异。

这意味着：如果随机划分训练集和测试集，**同一种材料的"孪生记录"会同时出现在两边**。模型等于提前看到了答案——测试集分数虚高，但换一种新材料就露馅。

**解法**：交叉验证时按化学式分组，保证同一种材料的所有记录只出现在同一折（GroupKFold 思路）。这样评估出来的分数才是模型对"没见过的材料"的真实泛化能力。

## 坑二：全局训练把体系差异平均掉了

把 21263 条数据混在一起训练，R² 看着挺高，但分体系看就露馅了：

- 铜氧化物（Tc 最高能到 133K 左右）
- 铁基超导（Tc 一般 30-60K）
- 氢化物（需要百万大气压，Tc 能到 200K 以上）
- 传统金属/合金（Tc 普遍 10K 以下）

不同体系的性质差异非常大。全局模型的 R² 是被数量多的体系"平均"出来的，对少数体系（比如氢化物）的预测可能完全不准。

**解法**：按体系分开评估，看每个体系的单独误差。如果某个体系样本太少，宁可明确标注"该体系预测置信度低"，也不要让全局指标掩盖问题。

## 实测结果

用梯度提升树（LightGBM）+ 按化学式分组交叉验证，全局 R² 能到 0.92 左右，比论文里常用的随机森林高一截。分体系看，铜基和铁基的表现明显好于氢化物（后者样本太少）。

顺带说一句：随机森林在这个数据集上容易过拟合（树太深时），梯度提升树加早停会稳很多。
